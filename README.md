# Tugas_Analisis_Clustering_menggunakan_K-Means-
Analisis clustering menggunakan algoritma K-Means untuk mengelompokkan data gempa bumi berdasarkan karakteristik seperti kedalaman (depth), magnitudo (mag), jumlah stasiun (nst), jarak minimum (dmin), RMS, dan gap. Analisis mencakup preprocessing data, statistik deskriptif, visualisasi, penentuan jumlah cluster, serta interpretasi hasil clustering.
